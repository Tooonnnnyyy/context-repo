# Release roadmap

## M0 · Public foundation

- Fresh, sanitized template repository; audit source, output, assets and Git metadata.
- CI, rollback tags, release/deployment instructions, Issues, changelog, worklog and handoff.

## M1 · Usable Context beta

- Real sign-up/sign-in and explicit local workspace option.
- Step-by-step resumable onboarding and one consistent responsive design system.
- Local Obsidian Markdown/folder/ZIP import with preview, source preservation and size limits.
- Notes, backlinks, tags, search, layered 2D/3D graph and private export.
- Per-note sharing selection and a public projection preview. Nothing published automatically.

## M2 · Product-line connections

- Quick Capture reviewed-note inbound draft contract and reciprocal return links.
- Connect IdeaMap identity with scoped authorization, revocation, sync receipts and deletion semantics.
- Explicit allowlisted note/project/blog projection; signed-out preview and owner-controlled unpublish.
- User-owned private GitHub repository sync with installation-scoped permissions. No raw access tokens in browsers.
- Read-only context retrieval for user-controlled agents and orchestration tools.

## M3 · Wider sources and social discovery

- Additional sources (opt-in, minimal scopes, preserving originals), enrichment/digests and user-controlled model providers.
- IdeaMap people/project discovery, matching and conversation integration.
- Retention/activation evidence and cross-device storage choices before adding payment plans.

## Release gates

M1 may ship as an explicit local-note beta. A real account is not cloud note storage. Account recovery and operational email must be verified before advertising a general-availability account service. Live note sync or IdeaMap connection is never claimed until verified end to end.
